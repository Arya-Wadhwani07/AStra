# Logo

The working AStra mark — a filled Phosphor planet in a coral-glow chip beside the "AStra" word in Unbounded — plus the `Eyebrow` label and the cropped closing `Wordmark`.

**Consumer provides:** `Logo` — optional `size` (px of the planet, default 22), `markOnly`, `decorative`. `Eyebrow` — children. `Wordmark` — children (default "AStra"), `decorative`.

- The planet chip is the only colour in the mark (`accent` with a `glow-1` drop shadow); the word stays `ink`. Nav size 22px; footer and closing sizes scale up.
- `Eyebrow`: `eyebrow` style (11px Schibsted Grotesk 600, 0.18em tracking, uppercase) in `accent-ink`.
- Closing wordmark: full page width in `wordmark` style, translated down so the page edge crops it.
- **Final name and logo are pending approval**; this is the working mark.
