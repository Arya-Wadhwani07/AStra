# MotionLoyaltyIntro

A decorative introduction to loyalty using the **Shared support** loop. Streams from many creators pour into one reservoir, standing for one shared balance.

- The worked example (sample data) follows the rules: 100 pts = $1, the creator sets a maximum % (Mira: 20% of $25 = $5 = 500 pts), and the fan pays the remaining $20.
- The footnote states that points have no cash value, can't be withdrawn and don't guarantee free merchandise. Nothing claims verified Spotify/YouTube activity.
- Redemption itself happens in checkout, which is **still**: no motion behind points maths.
