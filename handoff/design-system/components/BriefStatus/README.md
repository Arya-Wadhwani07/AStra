# BriefStatus

The shared project brief's version and each selected participant's confirmation of it.

**Consumer provides:** `title`, `version`, `edited`, `participants` (`{name, role, confirmed}`), optional `state` (`active`), `changed` (shows the new-version banner), `action`.

- Labelled "Shared plan · not a contract". A project becomes Active only when every selected creator confirms the **latest** version; any edit creates a new version and resets confirmations.
- Show dated history, Report and Withdraw (before confirmation) nearby.
