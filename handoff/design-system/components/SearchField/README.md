# SearchField

`TextField` preset for search, with a leading magnifier and a clear button once there's a value, wrapped in `role="search"`.

**Consumer provides:** `placeholder` (say what can be searched), `value` / `defaultValue`, optional visible `label`, `size`.

- Audience discovery searches name, discipline, skill and supplied location. Creator-only opportunities never appear in audience search results.
- Pair with filter `Chip`s underneath; show a "Clear filters" action in no-results states.
