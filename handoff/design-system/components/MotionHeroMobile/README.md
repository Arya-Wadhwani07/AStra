# MotionHeroMobile

The same hero at 390 × 800 using the 9:16 loop (`astra-hero-loop-9x16`).

- The sculpture sits in the top 55%. Copy and full-width actions sit in the bottom 42% text-safe band under a bottom-up scrim.
- The menu is a Phosphor `list` `IconButton`. The pause control sits bottom-right, above the safe band's padding.
